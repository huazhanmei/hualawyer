# 委托文书生成器 · 使用说明

福建知信衡律师事务所 · 接受委托时自动生成委托代理合同、授权委托书、法定代表人身份证明。

## 启动

双击 `启动.command`，浏览器自动打开 http://127.0.0.1:5092 。
（服务仅监听本机 127.0.0.1，外网无法访问；证件识别全部在本机完成，不上传任何服务器。）

## 使用流程

1. **上传证件**
   - 自然人当事人：身份证照片 / 扫描件 PDF；
   - 法人当事人：企查查企业详情页截图（含企业名称、统一社会信用代码、法定代表人、注册地址的页面）。
2. **核对信息**：OCR 识别结果会自动填入表单，逐项核对（身份证号自动做校验位验证，校验不符会红字提醒）；补充被告姓名、案由、代理阶段、代理权限、联系电话（必填）等。
3. **生成文书**：点"生成文书"，按当事人类型自动输出——
   - 自然人：委托代理合同、授权委托书（2 份），证件号码显示为"身份证号码"；
   - 法人：委托代理合同、授权委托书、法定代表人身份证明（3 份），证件号码显示为"统一社会信用代码"，需填法定代表人姓名与职务。
   文件保存在 `output/委托人-案由-编号/` 目录，网页可直接下载，也可点"在访达中打开"。

## 接入律所真实模板（重要）

当前 `templates_docx/` 下已放入律所真实模板（`示例-授权委托书.docx`、`示例-委托代理合同.docx`、`示例-法定代表人身份证明.docx`，由 WPS 的 .doc 自动转换而来，启动时自动完成）。如需更换：

1. 在律所现行的三份 Word 模板中，把需要自动填充的位置改写为**全角方括号占位符**，如：
   `甲方（委托人）：【委托人姓名】`、`因【案由】纠纷一案`、`【年】年【月】月【日】日`；
2. 打开网页顶部"模板管理"页，上传这三份 .docx（.doc 老格式放入 `templates_docx/` 后重启也会自动转换）；
3. 系统会自动猜测每个占位符对应的字段，核对/修正后点"保存映射"；
4. 之后再生成即使用真实模板。示例模板可被同名文件覆盖，也可以和真实模板并存。

### 可用数据字段

| 字段 | 含义 | 来源 |
|---|---|---|
| client_name | 委托人姓名/名称 | OCR / 手填 |
| client_gender / client_ethnicity / client_birth | 性别/民族/出生日期 | 身份证 OCR |
| client_address | 住址/住所 | OCR / 手填 |
| client_id | 身份证号 / 统一社会信用代码 | OCR / 手填（身份证号本地校验） |
| client_phone | 联系电话 | 手填（必填） |
| legal_rep / legal_rep_duty | 法定代表人姓名/职务 | 企查查截图 OCR / 手填（法人均必填） |
| opponent_name | 被告姓名/名称 | 手填（必填） |
| case_reason | 案由 | 手填（必填） |
| agency_stage | 代理阶段（一审/二审/再审/执行等） | 手填（必填） |
| auth_scope | 代理权限 | 手填 |
| contract_no | 合同编号 | 手填（不填则保留占位符） |
| sign_date / sign_year / sign_month / sign_day | 签订日期 | 手填，默认今天 |
| id_label | 证件类型标签（身份证号码 / 统一社会信用代码） | 按当事人类型自动 |

## 技术说明

- OCR：macOS 系统自带 Vision 框架（中文准确率高），PDF 先按 3 倍分辨率转图再识别；
- 填充：python-docx 段落级替换，保留模板原有字体、页眉、表格格式；
- 身份证号：18 位校验位（GB 11643）本地验证，不符即拒绝生成并提示；
- 生成逻辑：字段为空时保留【占位符】原样，便于打印前人工补填，不会静默漏填。

## 文件结构

```
委托文书生成器/
├── 启动.command        # 双击启动
├── app.py              # Web 服务
├── ocr.py              # 本地 OCR（Vision）
├── parsers.py          # 身份证/企查查字段解析与身份证校验
├── docgen.py           # docx 模板占位符替换
├── demo_templates.py   # 示例模板生成
├── web/index.html      # 网页界面
├── templates_docx/     # 模板库（示例模板 + 上传的真实模板）
├── mappings.json       # 占位符 → 字段 映射
└── output/             # 生成的文书（按 委托人-案由-编号 分目录）
```
